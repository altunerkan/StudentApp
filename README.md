# Student Management System

A desktop application developed with C# WinForms and SQLite for managing student records.

## Features

- Add new students
- Update student information
- Delete students
- Search students by name
- Display passed students
- Display failed students
- Show all students
- Automatic pass/fail status calculation
- Average grade calculation
- Passed/failed student statistics
- Input validation
- Delete confirmation dialog

## Technologies

- C#
- .NET WinForms
- SQLite
- ADO.NET

## Database

The application uses SQLite to store student information.

Stored fields:

- Id
- Name
- Age
- Grade

## How to Run

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Restore NuGet packages if necessary.
4. Run the project.
